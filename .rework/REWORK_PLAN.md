# REWORK_PLAN (S0). Facts: see APP_BRIEF.md. Design: handoff DESIGN_SYSTEM.md "Pasture".

## Approach

- **S1 (theme kit)** does the heavy lift once: new `theme/` from handoff `tokens.ts` (palette + semantic `color`, `type`, `space`, `radius`, `motion`), Nunito bundled, old `colors.*` keys re-pointed or codemodded, and the shared kit (`components/ui/`: ChunkyButton, Pill, StatTile, SpeechBubble, StreakWeek, CelebrationScaffold, Card, Sheet, ProgressBar, EmptyState) built, with a `/_design` route showing them. Existing `ui.tsx` / `onboarding*.tsx` become thin wrappers over the kit, so **every screen inherits the new look on S1**, and S2 only does per-screen layout + character slots.
- Palette is retunable from one file: `theme/palette.ts` (raw hex) → `theme/tokens.ts` (semantic). Nothing else holds a hex (lint check in S3).
- Old-key mapping (decide in S1, mechanical codemod): `Gold`→`primary` (actions) / `reward` (seeds), `Ink`→`text`, `muted`→`textSecondary`, `surface`→`surface`, `paper`→`bg`, `border`→`border`, `inactive`→`textTertiary`/`disabledFill`, `danger`→`error`, `success`→`success`, `goldSoft`→`primaryTint`, `Mat`→`surfaceSunken`, `splash*`→`brand`.
- Typography: Nunito everywhere (incl. Bible reader text; body 17/26, never caps/ExtraBold for verses). Replaces Cormorant + Lora.
- Tab bar stays the native system tab bar (Liquid Glass/Material) with `tintColor` meadow700. The reference's custom pill tab bar is NOT built: loses native behavior and Android support for no feature gain.

## Risks / unknowns

- **Parallel queue collision**: `/clear-issues` builders are editing the same onboarding files and `theme/tokens.ts`. S1 touches every file: pause the queue and merge S1 as one PR before any batch.
- **Uncommitted work** in `2.tsx`, `12.tsx`, `onboarding/_layout.tsx`, `onboarding-12.test.tsx`: needs to land (or be stashed) before S1.
- **Rive on web**: `pnpm verify` screenshots the web export; Rive RN is native-only. LambView needs a static-PNG fallback on web or e2e breaks.
- **New deps need approval** (CLAUDE.md): Rive runtime (dev build + prebuild + pod install, no Expo Go), `expo-haptics`, `react-native-svg` (if icons need it). Splash bg moves `#F7C341` → `#243E69` in app.json (native rebuild).
- **Nunito 700 missing**: handoff ships only 600 and 800 TTFs but `tokens.ts` names `Nunito_700Bold`. Plan: use 600 + 800 only.
- **Unbuilt onboarding screens** (8, 14, 16, join) will be built by other issues. They must use the new kit after S1 lands.
- **Superwall** (`superwall/`, untracked) paywall `pro` is outside this rework. Not restyled.
- Each Jest/Playwright test touching colors, fonts or copy will need updating; every S2 batch must keep `pnpm verify` green.
