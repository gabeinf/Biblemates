## What the app does

- A small-group (circle) Bible reading app: a circle picks a 7-day study, everyone reads the same passage daily.
- Home shows circle progress, today's shared reading, circle activity, a group question, encouragement chips, prayer requests.
- Bible tab = full reader (translations, highlights, bookmarks, private notes, circle reflections, "mark today read").
- Study tab = the 7-day journey (Read → Reflect → Connect) and reveal of group reflections.
- Scripture chat (Fastify + Socket.IO + pgvector search) opens from Home. Push reminders + circle activity via Supabase functions.

## Core flows

**Onboarding (create path, 19 steps):** 1 splash → 2 hook → 3 intent → 4 proof → 5 voices → 6 rhythm → 7 stakes teaser → 8 together → 9 fork → 10 days/wk → 11 rules → 12 stakes → 13 name → 14 commitment → 15 invite → 16 rating → 17 notifications → 18 source → 19 sign-up → (auth guard) `/circle-setup`.
**Join path:** …9 → `join` → 13 → 14 → 16 → 17 → 18 → 19 (skips 10–12, 15).

- Draft is in-memory only (`lib/onboarding-draft.ts`, schema in `packages/shared`). Step 19 does NOT yet write the draft (`TODO(#23)`): days/week, stakes, intent, source are never persisted.
- Mid-flow app kill restarts at 1. Steps 8/14/16/join render `PlaceholderStep`.
  **Daily reading + check-in:** Home "Continue reading" → `/bible?book&chapter&verse` → reader shows done banner → tap → `useMarkDayComplete` (optimistic) → DB insert `day_completions` → trigger writes `activity`.
  **Accountability:** circle of N members; Home shows avatars with active-today ring, per-day dots (count/members), activity feed (6), group question, "Pray for X" chips (`encouragements` kind `praying`), prayer requests (I prayed / Mark answered). No visibility toggles beyond reflection private/circle.
  **Streaks:** none. No streak, seed, currency, shop or lamb concept exists in code or schema.
  **Notifications:** push permission asked in onboarding 17 and again by `registerForPush` once in a circle; `functions/push` (activity → Expo push, respects prefs/quiet hours), `functions/daily-reminder` (hourly cron, per-user hour); tap → `data.url` (`/study` or `/home`).
  **Settings (Profile):** edit profile, invite code copy/share, members list, toggles (daily reminder + hour, circle activity, encouragement, quiet hours), sign out, leave circle.

## Events (what a celebration/animation can hook)

| event                               | file:function                                                                                   | data available                                                     |
| ----------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Check-in complete (me)              | `bible.tsx:224` `markDone.mutate` → `queries.ts:useMarkDayComplete` (onMutate/onSettled)        | day_number, circleStudyId, userId; completions list gives N/M done |
| Friend checked in                   | `queries.ts:useCircleRealtime` (activity INSERT `completed_reading`) + push                     | actor_id, meta.day_number, meta.day_title                          |
| Group fully checked in today        | **not an event**; derivable in `home.tsx` (`activeToday.length === memberList.length`)          | members, completions                                               |
| Streak extended/broken              | **none**; derivable client-side from `day_completions.completed_at` (new logic)                 | no stored value                                                    |
| Study complete (everyone, last day) | DB trigger `on_day_completed` → activity `milestone` (meta.type `study_completed`, study_title) | realtime + push "Milestone 🎉"                                     |
| Member joined                       | trigger `on_member_joined` → activity `joined`                                                  | actor_id                                                           |
| Nudge/encouragement sent            | `queries.ts:useEncourage` onSuccess (`home.tsx` chips + "I prayed for you")                     | toUser, kind heart\|praying, prayerRequestId                       |
| Nudge/encouragement received        | activity `encouraged` (target_user_id, meta.kind) via realtime + push                           | actor, kind                                                        |
| Reflection shared / prayer posted   | activities `shared_reflection`, `prayer_request`                                                | actor, subject_id                                                  |
| Prayer answered                     | `queries.ts:useMarkPrayerAnswered`                                                              | prayer id                                                          |
| Study started                       | `queries.ts:useStartStudy` (`study.tsx`)                                                        | study id                                                           |
| Daily reminder / push tap           | `functions/daily-reminder`; `(main)/_layout.tsx:useNotificationRouting`                         | url                                                                |
